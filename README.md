# 🚀 Planova – Habit Tracker Mobile App

Planova, kullanıcıların günlük / haftalık / aylık alışkanlıklarını takip etmelerini sağlayan,
**oyunlaştırma (gamification)** yaklaşımıyla motivasyonu artıran bir mobil uygulamadır.

Kullanıcılar alışkanlıklarını tamamladıkça **puan kazanır**, **seviye atlar** ve **rozetler (badges)** elde eder.
Uygulama React Native + Expo altyapısıyla geliştirilmiştir ve modern bir backend API ile haberleşir.

---

## ✨ Özellikler

- 🔐 JWT tabanlı kullanıcı kimlik doğrulama (Login / Register / Logout)
- 📋 Alışkanlık ekleme, listeleme ve silme (soft delete)
- ✅ Günlük alışkanlık tamamlama (tick sistemi)
- 🏆 Puan, seviye ve rozet (badge) sistemi
- 🎉 Yeni rozet kazanıldığında **popup bildirim**
- 📊 Detaylı istatistik ekranı
  - Aylık takvim görünümü (gün gün tamamlandı / tamamlanmadı)
  - Günlük & haftalık başarı oranları
  - Alışkanlık bazlı ilerleme barları
- 🤖 AI Asistan entegrasyonu
- 🎨 Modern ve responsive mobil UI
